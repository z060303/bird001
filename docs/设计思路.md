# 设计思路

## 1. 项目要解决什么

仿生鸟控制板需要同时处理姿态感知、舵机调节、气压测量和动力控制。固件把“按固定节奏采样与控制”和“可能耗时的串口输出”分开，优先保证横滚控制使用新鲜的姿态数据。

当前可执行的主流程是 **IMU → 横滚角 → 舵机**。气压数据用于观测和后续高度控制基础； SBUS 接入飞控闭环，启用电机自动启动。

## 2. 上电后发生什么

1. `main.c` 初始化时钟、GPIO、串口、I2C 和定时器，调用 `BLDC_Init()`。默认 `BLDC_AUTOSTART=0`，因此不调用 `BLDC_Start()`。
2. `App_Start()` 先把舵机设置到 72.5° 中位，创建静态任务和队列，再启动 FreeRTOS。
3. IMU 任务读取加速度和角速度，更新姿态估计，并把最新横滚角写入长度为 1 的队列。
4. 控制任务取最新样本，执行方向、比例、限幅和过期判断，更新舵机目标角度。
5. 气压任务独立采集，日志任务从队列读取结果，经 USART6 发出。

长度为 1 的横滚队列避免旧数据堆积；控制任务无需等待 I2C 或串口。日志队列满时丢弃新日志并计数，避免打印拖慢控制。

## 3. 周期与失效处理

| 任务 | 正常周期 | 主要工作 |
| --- | ---: | --- |
| `imu_8ms` | 8 ms | I2C2 读取 ICM-42688-P，更新姿态 |
| `roll_servo` | 8 ms | 使用最新横滚角，更新 TIM4_CH3 |
| `baro_20ms` | 20 ms | I2C1 读取 MS5611，计算温度/气压/高度 |
| `uart_log` | 队列触发 | USART6 中断发送记录 |

任务使用 `xTaskDelayUntil()` 保持释放节奏；超时后跳过错过的周期。IMU 或气压计初始化失败时约每秒重试。IMU 数据无效、角度非有限值或样本年龄超过 40 ms 时，控制目标回到中位。`g_app_diagnostics` 提供样本数、错误、超时、日志丢弃等计数。

## 4. 横滚控制如何映射

默认关系为 `目标舵机角 = clamp(72.5° - 横滚角, 0°, 145°)`。例如横滚 `+30°` 时目标约 `42.5°`，`-30°` 时目标约 `102.5°`。这只是一套安装方向约定，机械方向需要上板核实；可在 `Core/APP/roll_control.h` 修改 `APP_ROLL_DIRECTION` 和 `APP_ROLL_GAIN`。

TIM4 的舵机 PWM 为 50 Hz、20 ms 一帧，脉宽约 500～2500 μs。控制任务每 8 ms 更新目标，并不意味着舵机 PWM 是 125 Hz。

## 5. 无刷电机模块的边界

`Core/BSP/BLDC.h` 提供两种编译期互斥模式：默认的开环六步换相，以及实验性的反电动势过零闭环。开环由 TIM1 产生 20 kHz 桥臂信号，TIM2 安排换相；闭环还使用 ADC1/ADC2 与 TIM5。默认状态两种模式都不会自动转动电机。

开环给定的是换相周期和占空比，**不测量真实转速**。闭环代码依赖改造后的三相采样网络，目前 `BLDC_BEMF_HARDWARE_READY=0`。请先完成 [硬件核对](硬件核对.md)，再考虑动力调试。

## 6. 接下来可以怎么扩展

- 在台架上记录 IMU 采样间隔、控制任务超时计数和舵机机械方向，调整安装方向与增益。
- 核实电机供电、自举、分压与示波器波形后，再设计电机与舵机联合控制。
- 为高度控制建立地面相对高度零点；当前串口中的 `alt_m` 是按标准气压换算的高度，不能直接当作离地高度。

以上是后续工作方向，不代表当前版本已经实现。
