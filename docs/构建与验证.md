# 构建与验证

## 工具准备

- CMake 3.22 或更新版本
- Ninja
- Arm GNU Toolchain，确保 `arm-none-eabi-gcc` 在 `PATH`
- 可选：STM32CubeProgrammer + ST-LINK（烧录）
- 可选：Python 3、`unicorn`、`pyelftools`（运行 ARM 模拟测试）

使用 STM32CubeMX 修改引脚时，保留 `Core/Src/main.c` 中的应用入口和 `Core/APP`/`Core/BSP` 代码，并检查 FreeRTOS 的 SysTick、SVC、PendSV 以及 USART6 中断优先级。闭环 ADC 寄存器配置在 BSP 中，不在 `.ioc` 中。

## 编译固件

在仓库根目录执行：

```sh
cmake --preset Debug
cmake --build --preset Debug
cmake --preset Release
cmake --build --preset Release
```

产物位于 `build/Debug/bird001.elf` 和 `build/Release/bird001.elf`。`CMakePresets.json` 通过 `cmake/gcc-arm-none-eabi.cmake` 指定 Cortex-M4F、硬件浮点和链接脚本。构建输出由 `.gitignore` 排除。

项目提供 `flash` 目标：当 CMake 找到 `STM32_Programmer_CLI` 时，可用 `cmake --build --preset Debug --target flash` 经 SWD 烧录。执行前应完成 [硬件核对](硬件核对.md)。

## 串口看什么

USART6：PC6 为 TX，PC7 为 RX，115200、8N1。输出示例：

```text
I,1234,12.34,-1.25,0.03
P,1240,101325.00,25.30,0.00
I,1242,ERR=1
```

`I` 后依次是毫秒 tick、横滚、俯仰、偏航角；`P` 后依次是毫秒 tick、Pa、°C 和基于标准气压换算的高度。`ERR` 表示本次读取失败。日志可能因队列满或串口错误而丢失；调试器中的 `g_app_diagnostics` 可查看计数。

## 逻辑测试与边界

应用层 ARM 模拟测试：

```sh
python -m pip install unicorn pyelftools
python tests/run_app_arm_test.py
```

测试调用实际的舵机/横滚控制与部分应用函数，并模拟 HAL/RTOS 边界。它不模拟真实任务切换、I2C 电气行为或舵机机械方向。当前仓库未包含旧版电机测试，因为旧测试引用了本版源码中不存在的 `BLDC_Speed.c` 与 RPM 接口；电机功能应在硬件修正后重新设计验证用例。
